# Симулятор агентов

Генератор нагрузки и истории для демо и нагрузочных тестов: 350 школ, 1000 ПК, 3 месяца
замеров (plan.md §15, сценарий 7). Ходит в сервер через тот же API, что и настоящий агент
(ADR-006): регистрирует устройства (`POST /api/devices/register`), шлёт замеры пачками
(`POST /api/measurements/batch`) с профилями «норма», «деградация по часам», «простой»,
«Wi‑Fi-замер», а также heartbeat и `POST /api/outages`. Школы берёт по районам из seed
(T-04). Повторный запуск дублей не создаёт.

Запуск — через Makefile, интерпретатором из `backend/.venv`:

```bash
make simulate n=1000 days=90      # n — количество ПК, days — глубина истории
```

Прямой вызов: `simulator/simulate.py --schools 350 --devices 1000 --days 90`.
