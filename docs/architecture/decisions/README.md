Если ADR расходится с `docs/product/plan.md`, прав ADR: он новее и принят осознанно.

Как добавить ADR: скопируйте любой файл, возьмите следующий номер, сохраните тот же формат (шапка со
статусом, датой и источником; разделы «Контекст», «Решение», «Последствия», при необходимости «Открыто»).
Имя файла — `NNN-slug.md` (латиницей, через дефис); добавьте строку с номером и заголовком в таблицу выше
в том же слиянии. Статус — «предложено» до слияния в `developing`, затем «принято».
