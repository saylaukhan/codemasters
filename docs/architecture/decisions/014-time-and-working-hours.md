# ADR-014 · Время: UTC в хранении, Asia/Almaty в интерфейсе, рабочие часы школы

**Статус:** принято · **Дата:** 2026-09-16 · **Источник:** ТЗ п. 2, п. 9, п. 11, п. 13, plan.md §4.2, §6

## Контекст
ТЗ п. 2 требует дату и время каждого замера, п. 9 — колонки «дата» и «время» в выгрузке, п. 13 — время
последнего измерения на карте, п. 11 — доступность не ниже 99 % за расчётный период. Школьные ПК выключают
на ночь (plan.md §16), и «ПК выключен» нельзя считать простоем линии. Замер может прийти через дни (ADR-006).

## Решение
- Хранение — `timestamptz` в UTC везде: `measurements.measured_at` и `received_at`, `heartbeats.ts`,
  `outages.started_at` / `ended_at`, `created_at` / `updated_at`. Агент шлёт RFC 3339 с оффсетом;
  `measured_at` — момент замера на ПК, `received_at` ставит сервер; разница — след офлайн-очереди.
- API отдаёт RFC 3339; панель и отчёты (XLSX, CSV, PDF) показывают Asia/Almaty (UTC+5). В панели
  единственное место форматирования — `web/src/lib/format.ts`; в экспорте пояс подставляет сервер.
- Рабочие часы школы: по умолчанию 08:00–18:00, пн–сб, Asia/Almaty; настраиваются на школу в админке
  (T-37). Слоты расписания замеров тоже задаются в Asia/Almaty и меняются в админке.
- Доступность = 1 − простой / время наблюдения, где время наблюдения — только рабочие часы; простой —
  интервалы `outages` плюс пропуски heartbeat. «Нет соединения» — нет heartbeat дольше 15 мин в рабочие
  часы; вне рабочих часов — «Нет данных» (только отображение, ADR-004).

## Последствия
- В коде нет «наивного» времени: Python — только aware-`datetime`, Go — `time.Time` с зоной из
  RFC 3339, TypeScript — только `format.ts`. Часовой пояс сервера значения не имеет.
- Доступность (п. 11) не считается без рабочих часов, поэтому они есть у каждой школы — по умолчанию из этого ADR.
- Кода пока нет: схема — T-02, heartbeat и простои — T-12, T-16, агрегаты — T-19.

## Открыто
- Границы «дня» и «часа» в `m_hourly` / `m_daily` и в тепловой карте час×день (ТЗ п. 5, часы ухудшения):
  для школы осмысленны сутки Asia/Almaty, а не UTC; решает T-19.
