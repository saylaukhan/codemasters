# ADR-013 · Веб-панель: Refine + Ant Design 5 с темой из DESIGN.md, русский интерфейс

**Статус:** принято · **Дата:** 2026-09-16 · **Источник:** ТЗ п. 4, п. 5, п. 13, plan.md §2, §11, §14

## Контекст
Панель по ТЗ п. 4, 5, 13 — десяток экранов с таблицами, карточками, фильтрами, графиками и картой ВКО
с цветными статусами. Frontend-разработчик один, срок — шесть недель (plan.md §14): рисовать компоненты
с нуля некогда, а разнобой статусов и цветов на карте, в списке и в карточке недопустим — по ним принимают решения.

## Решение
- Стек: React 18 + TypeScript + Vite, Refine поверх Ant Design 5, TanStack Query (plan.md §2).
  Провайдеры, роутер и настройка Refine — в `web/src/app/`.
- Тема: CSS-переменные в `web/src/styles/tokens.css` (светлая и тёмная) из `DESIGN.md`;
  `web/src/styles/theme.ts` строит из них тему `ConfigProvider`. Hex-цвета в компонентах запрещены.
- Свои компоненты — только обёртки над AntD в `web/src/components/ui/`; доменные — в
  `components/<домен>/`, страницы — в `src/pages/<домен>/`.
- Графики — Apache ECharts; карта — MapLibre GL JS с GeoJSON районов ВКО и публичными OSM-тайлами на
  демо (свой tileserver — позже). Стили обоих — из `DESIGN.md`, статусные цвета — те же токены, что в таблицах.
- Интерфейс по-русски, строки в компонентах, без i18n-фреймворка (ADR-010). Статусы и подписи — только
  через `web/src/lib/labels.ts`, числа и даты — через `web/src/lib/format.ts` в Asia/Almaty (ADR-014).
- Клиент к API генерируется из OpenAPI в `web/src/api/generated/*` (ADR-009); руками не правится.
- Правило экрана: одна Action-кнопка, три состояния (загрузка / пусто / ошибка), проверка в обеих темах и на 1024px.

## Последствия
- Новый экран — страница плюс обёртки; дизайн-решения принимаются в `DESIGN.md`, не в задаче.
- Строка статуса, которой нет в `labels.ts`, — ошибка; «Нет данных» отображается, но не является
  статусом качества (ADR-004). Панель узнаваемо «антдовская» — принято; отклонения делаются токенами.
- `make check-web` (eslint, `tsc --noEmit`, vitest, `vite build`) входит в `make check` перед слиянием.
- Кода пока нет: каркас, тема и вход по JWT — T-21, экраны — T-22…T-28, админка — T-34…T-39.
