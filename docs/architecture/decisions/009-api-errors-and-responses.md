# ADR-009 · Формат ошибок и ответов API

**Статус:** принято · **Дата:** 2026-09-16 · **Источник:** ТЗ п. 6, п. 9, plan.md §10

## Контекст
ТЗ п. 6 разрешает свою структуру API при сохранении требуемой функциональности (список методов в п. 6 —
пример минимального набора), п. 9 добавляет JSON-экспорт для
внешних систем. Потребителей три — агент на Go, панель на TypeScript, внешние интеграции, — и все должны
одинаково разбирать ошибки и списки. Swagger прикладывается к поставке (plan.md §10): схема должна быть точной.

## Решение
- Пути без версии: `/api/...` (ТЗ п. 6, plan.md §10). Версионирование — новым ADR, если понадобится.
- Ошибки — `application/problem+json` (RFC 9457): `type`, `title`, `status`, `detail`, `instance`; при
  валидации — `errors[]` с `field` и `message`. `type` — стабильный машинный код, по нему ветвится клиент;
  `detail` — текст для человека. Стандартный `{"detail": ...}` FastAPI наружу не выходит: все
  исключения переводит middleware ошибок в `app/main.py`.
- Списки — `{items, total, page, page_size}`. Поля JSON — snake_case; в TypeScript — camelCase,
  маппинг только в `web/src/api`.
- Ответ агенту на замер: 201 — принят, 409 — дубль по `measurement_uuid` (ADR-006 «Офлайн-очередь и
  идемпотентность»); оба означают «запись можно удалять из очереди».
- Авторизация: агент — `Authorization: Device <token>`; панель — JWT (access 15 мин в памяти, refresh в httpOnly cookie).
- OpenAPI — единственный контракт: `make openapi` экспортирует схему в `docs/reference/openapi.json`
  и генерирует `web/src/api/generated/*`; оба руками не правятся. Каждый эндпоинт описан
  Pydantic-схемами запроса и ответа в `app/schemas/` — поле без схемы не попадёт в панель.

## Последствия
- Изменение контракта = правка схем + `make openapi` + перегенерированный клиент в одном слиянии;
  расхождение «бэкенд отдаёт, панель не знает» ловит `make check-web` (`tsc --noEmit`).
- Панель не пишет ручных типов для ответов API; агент разбирает только `status` и `type`. Описание
  API для поставки (T-57) получается из той же схемы без ручной синхронизации.
- Кода пока нет: контракт и генерация — T-03, первые роутеры — T-14, T-15.
